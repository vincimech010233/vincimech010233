# World models: marco comparativo para evaluación reproducible

**Estado:** borrador de investigación independiente; no presenta resultados experimentales propios.

## Pregunta

¿Qué compromisos hay entre coste, datos, control, latencia y capacidad predictiva al elegir una arquitectura de world model para un sistema simulado?

## Enfoque propuesto

La selección debe partir de una tarea acotada y métricas reproducibles: error de predicción, coste de entrenamiento, memoria, latencia de inferencia y comportamiento fuera de distribución. Las arquitecturas se comparan bajo la misma carga y presupuesto de cómputo.

## Próximo artefacto verificable

Un repositorio pequeño con un entorno de simulación no sensible, baselines versionados, scripts de instalación y ejecución, una tabla de resultados generada por código y límites claros sobre datos, costes y generalización.

## Requisito antes de presentar resultados

Los papers, licencias y versiones de las arquitecturas deben enlazarse. Los precios y requisitos regulatorios temporales deben proceder de fuentes fechadas. Las recomendaciones se presentan como hipótesis razonadas, no como hechos.
