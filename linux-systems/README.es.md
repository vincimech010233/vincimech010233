## Trabajo técnico publicado

- [Linux Resource Benchmark](https://github.com/vincimech010233/linux-resource-benchmark) — CLI reproducible para microbenchmarks acotados de CPU, memoria, disco y procesos en Linux, información del sistema e informes estadísticos.
- [Linux Application Incident Lab](https://github.com/vincimech010233/linux-application-incident-lab) — incidencia sintética local HTTP 502 con Nginx/Python, diagnóstico mediante logs del proxy, corrección del puerto upstream y recuperación comprobada. No se probó Docker.

Juntos muestran medición acotada del sistema, diagnóstico de red local y recuperación de servicio. El soporte a usuarios reales y los tickets de producción siguen fuera de la evidencia.
