## Repositories

- [Junior Developer Project Collection](junior-developer-projects/README.md) — 12 learning exercises across several technologies, with synthetic data, scope and verification status documented.
- [UncertaintyLab](../uncertaintylab/README.md).
- [Python](https://github.com/vincimech010233/python) — automation, data processing and technical prototypes.
- [JavaScript](https://github.com/vincimech010233/javascript) — web exercises and a local chat prototype with static-file and message-delivery tests, also run in CI. The Marvel exercise is excluded because its image provenance is unverified.
- [Quantum Chess](https://github.com/vincimech010233/Quantum-Chess) — TypeScript/React probabilistic chess prototype with 37 regression tests, state invariants, CI and a reproducible build with local styles. It is not a complete chess engine.
- [Quantum Computing Journey](https://github.com/vincimech010233/QuantumComputingJourney-) — studies and notebooks using Qiskit and PennyLane.
- [Machine Learning Basics](https://github.com/vincimech010233/MachineLearningBasics) — machine-learning exercises and notes.
- [Rust, C and Assembly Exercises](https://github.com/vincimech010233/rust_asm) — educational archive of low-level exercises.
- [x86-64 ABI Lab](https://github.com/vincimech010233/x86-64-abi-lab) — original C and NASM functions for the System V AMD64 ABI, checked with C/ASM differential tests and sanitizers on the C harness. Assembly accesses are not instrumented; this is not a formal memory-safety proof.
- [simdjson Streaming Complexity Study](https://github.com/vincimech010233/simdjson-streaming-complexity-study) — reproducible C++ and Python study of streaming JSON parsing with controls, bounded execution and follow-up on an initial anomaly that did not recur.
- [Axiomize Quantum Skills 2.0](https://github.com/vincimech010233/axiomize-quantum-skills-2.0) — Python engine for scientific modeling and branching reasoning inspired by quantum concepts.
- [Drosophila Whole-Brain State Decomposition](https://github.com/vincimech010233/drosophila-whole-brain-state-decomposition) — reproducible software and observational analysis of neural-behavioral coding, with explicit limits on conclusions.
- [NeuroControl-Kev Lab](https://github.com/vincimech010233/NeuroControl-Kev-Lab) — reproducible CPU-only experiment comparing the Kev action-selection backend with a rules baseline after a simulated safety barrier.
