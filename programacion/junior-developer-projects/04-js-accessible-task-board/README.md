# Accessible Task Board

A zero-dependency browser task board. Add tasks, mark them complete, filter the list, and persist state in localStorage. Data stays in this browser.

## Run
Open `index.html` in a browser. No build step or server is needed.

## Features
- Semantic HTML and keyboard-operable controls
- Add, complete, delete and filter tasks
- Persistent browser storage with a safe empty-state fallback
- Responsive layout and clear empty state

This is a portfolio demo; tasks are stored only in the current browser profile.
