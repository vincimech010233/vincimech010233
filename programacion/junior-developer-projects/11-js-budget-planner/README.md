# Simple Budget Planner (JavaScript)

A responsive browser app to log expenses, filter by category, and compare spending with a monthly limit. Data stays in the browser's localStorage. No build step or dependencies.

Open `index.html` in a browser. The default budget is €500; change it in the form. Use sample values for a quick demo.

Skills: semantic HTML, accessible forms, JavaScript modules/functions, local persistence, responsive CSS, input validation.
