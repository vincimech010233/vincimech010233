# OSINT

Esta sección está reservada para investigación en fuentes abiertas que pueda documentar de forma trazable su alcance, fuentes, metodología, limitaciones y revisión legal/ética.

No se incluyen informes que puedan sugerir afiliación institucional, formular acusaciones sobre entidades o personas, o presentar afirmaciones sin fuentes reproducibles.

Cuando se publique una investigación, deberá distinguir hechos verificados, observaciones, inferencias e hipótesis.
