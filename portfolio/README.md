## Criterios editoriales

- Las hipótesis se separan explícitamente de resultados reproducidos.
- Las cifras y afirmaciones técnicas requieren fuentes primarias antes de convertirse en conclusiones.
- No se usan clasificaciones, logos, destinatarios ni formatos que sugieran afiliación institucional.
- Los proyectos de software se priorizan cuando incluyen instrucciones reproducibles y pruebas ejecutables.
