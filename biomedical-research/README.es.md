# Notas de investigación biomédica

[English](README.md)

Esta sección reúne trabajos exploratorios sobre datos biomédicos y viabilidad de diseño de proteínas. Son registros de investigación, no productos clínicos ni resultados biológicos validados.

- [Viabilidad de datos de ARN sanguíneo para investigar el adenocarcinoma pulmonar temprano](https://github.com/vincimech010233/lung-adenocarcinoma-data-feasibility) — revisión de metadatos de cohortes públicas; sin modelo diagnóstico ni validación clínica.
- [Estudio de viabilidad de minibinders para EGFR](https://github.com/vincimech010233/egfr-minibinder-feasibility-study) — preparación de secuencias y estructuras; el intento del modelo no generó candidatos.

Ambos proyectos indican qué se comprobó, qué sigue sin verificar y qué evidencia haría falta. No se publican datos de pacientes.
