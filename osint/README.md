# OSINT

Esta área reúne herramientas y proyectos de investigación en fuentes abiertas con alcance documentado, fuentes trazables, limitaciones visibles y criterios legales y éticos explícitos.

## Proyectos públicos

- [OSINT Evidence Pipeline](https://github.com/vincimech010233/osint-evidence-pipeline): CLI reproducible en Python que recopila metadatos públicos de proyectos desde GitHub y PyPI, conserva procedencia y genera informes JSON y Markdown. Limita GitHub a repositorios de organizaciones y excluye campos personales.

Los informes y herramientas de esta área no deben sugerir afiliación institucional, formular acusaciones sobre entidades o personas ni presentar afirmaciones sin fuentes reproducibles. Los hechos observados deben distinguirse de las interpretaciones, inferencias e hipótesis.
