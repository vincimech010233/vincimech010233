## Trabajo técnico publicado

- [Linux Application Incident Lab](https://github.com/vincimech010233/linux-application-incident-lab) — incidencia sintética local con Nginx/Python, HTTP 502, comprobación directa de salud, logs del proxy, análisis de causa, recuperación, caso manual y prueba automatizada de regresión. Se verificó con Nginx local, no con Docker.
- [Linux Resource Benchmark](https://github.com/vincimech010233/linux-resource-benchmark) — mediciones e informes acotados del sistema como evidencia complementaria de diagnóstico.
- [OSINT Evidence Pipeline](https://github.com/vincimech010233/osint-evidence-pipeline) — documenta respuestas incompletas de APIs públicas y fallos de colectores; evidencia relacionada de manejo de errores.

El laboratorio documenta un ciclo completo de diagnóstico controlado. No se atribuyen incidencias de clientes reales, tickets de usuarios ni soporte de un producto desplegado.
