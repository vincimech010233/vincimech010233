## 1.0.1 — historical corrected local package, 2026-10-11

Changes in the earlier Codex-assisted corrected package included whole-authority
validation, empty fragment/port and repeated-dot handling, multicast classification,
bounded JSON reads, duplicate-key rejection, observation-type validation and explicit
recursion-error handling. These include both reproduced repairs and defensive hardening;
an added regression does not mean every tested form failed in the earlier package.
The package also documented permissive PASS/exit semantics.
Historical package hashes and provenance appear in `evidence/source-provenance.json`.
